# Картки для поширення посилань

Генератор `/og/[...path]` повертає PNG 1200×630. Open Graph і Twitter використовують
однакову картку через `getSocialMetadata` у `src/shared/og/metadata.ts`.

## Вигляд

- Новина: оригінальне фото з CMS праворуч, чорний градієнт під заголовком, дата
  публікації. Фіолетового виділення заголовка за замовчуванням немає.
- Новина без фото або з недоступним фото: абстрактний фон факультету.
- Головна та розділи: спільна геометрична графіка; заголовок, підпис і необовʼязкове
  виділення налаштовуються в `src/shared/og/config.ts`.
- Освітня програма: назва, код спеціальності та рівень із CMS.
- Розклад: курс і рівень із конфігурації джерела.

Абстрактний фон `public/images/og/background.png` створений вбудованим ImageGen із погодженого
референсу. Він доступний за `/images/og/background.png`. Генератор читає цей PNG
з файлу й використовує його без HTTP-запиту до сайту.
Фон містить зернисту графіку та фіолетові квадрати; генератор додає лише живу типографіку. Геометрія
не перемальовується кодом і додаткове затемнення до цього фону не застосовується.

`highlight` у конфігурації вказує слово чи фразу для виділення в заголовку, незалежно
від наявності `lines`. Без `lines` текст переноситься автоматично; з `lines` зберігаються
задані рядки. Виділяється перший точний збіг у заголовку або в кожному заданому рядку.
Приберіть це поле, щоб вимкнути виділення для сторінки. На головній виділяється лише «інформатики»;
«та» залишається білим поруч із виділеним словом у тому самому рядку. Параметр `?highlight=off` дозволяє переглянути
картку без виділення, не змінюючи її метадані.

## Локальний перегляд

Після `bun run dev`:

- `/og/home` і `/og/home?highlight=off`
- `/og/news/faculty`
- `/og/news/faculty/formula-uspikhu-dlia-studentiv-fakultetu-matematyky-ta-informatyky`
- `/og/educational-programs`
- `/og/educational-programs/f3-kompiuterni-nauky-bakalavr`
- `/og/rozklad/bachelor-1`
- `/og/normatyvni-dokumenty`

Фотографії перетворюються Sharp із AVIF у PNG; кадрування враховує `focalX`/`focalY`
медіафайлу. Пікселі фото не генеруються ШІ. Локальні шрифти Manrope підтримують
українську й постачаються з ліцензією OFL, без завантаження шрифтів під час запиту.

URL зображення містить версію шаблону `v=3`. Для новин і програм додається дата
оновлення CMS, а для новин також дата оновлення обкладинки. Дані використовують
наявний кеш CMS і публічні права доступу. HTTP-кеш зображення: браузер 5 хвилин,
CDN 1 година. Після зміни дизайну збільште версію в `getSocialImageUrl`, щоб отримати
новий URL. Соцмережі додатково кешують свої превʼю; локальний сервер не доступний
їхнім ботам.

Перевірки: `bun test src/shared/og`, `bunx tsc --noEmit`, `bun run lint`.

## Перевірка в соцмережах

`localhost` доступний лише локально; боти соцмереж не можуть зчитати його метадані.
Для реального превʼю потрібен тестовий деплой або тимчасовий публічний HTTPS-тунель.
`NEXT_PUBLIC_BASE_URL` має вказувати на цю публічну адресу до запуску/збірки Next.js,
інакше `og:image` й надалі посилатиметься на production. Після зміни адреси сервер
потрібно перезапустити. Одного завантаження PNG як фотографії в Telegram недостатньо
для перевірки превʼю посилання.
